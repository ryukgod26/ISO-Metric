# ISO METRIC
ISO-Metric is a 2D isometric puzzle-exploration game set in a decaying cyberpunk simulation. You play as an autonomous AI drone named Unit 734, known as a "System Archivist." To the naked eye, the futuristic city is falling apart—buildings are turning into wireframes, civilians are frozen, and textures are missing. However, you are equipped with a specialized camera that can see the simulation's true "source code" and manipulate reality by taking photographs.
